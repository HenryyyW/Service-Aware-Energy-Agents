## 1. Hard constraints (ACM e-Energy / acmart two-column)

| Rule | Requirement |
|---|---|
| Layout | Two-column. Single-column figure ≈ **3.33 in** wide; full-width ≈ **7.00 in** |
| Vector | Submit **PDF** (preferred) or SVG. Raster previews ≥ 600 dpi PNG |
| Fonts | **Embed all fonts** in the PDF (TrueType, `pdf.fonttype: 42`) |
| Figure font | Sans-serif, base **8 pt**, ticks/legend **7 pt** — never below ~7 pt |
| Captions | **Figure captions below**, **table captions above** |
| Colour | Colour-blind safe **and** legible in grayscale (strip-copy test) |
| Reproducibility | Every figure is generated by a script from committed artifacts; no hand edits |

> Widths are the acmart **sigconf** nominal values. Confirm them against the exact
> camera-ready template before submission; the helpers accept overrides if the class differs.

## 2. Palette

- **Controllers → colour** — Okabe-Ito, identical to `experiments/make_figures.py` so a controller
  keeps one colour across F1–F8:

| controller | colour | | controller | colour |
|---|---|---|---|---|
| `rule_based` | `#0072B2` | | `rl` | `#E69F00` |
| `multi_agent` | `#D55E00` | | `llm_agent` | `#56B4E9` |
| `centralized` | `#009E73` | | `llm_agent_verified` | `#000000` |
| `mpc` | `#CC79A7` | | | |

- **Pricing regime → marker shape** (F7): `tou_solo` ○ · `pool_tou` □ · `lmp` △ · `p2p` ◇.
- **Accent:** IEEE blue `#00C0EF` (matches the frontend accent after the 2026-11-01 recolor).
- **Price (neutral, non-valence):** ramp `#475569 → #64748B → #94A3B8 → #B9A48C → #D8BE9E`
  (matches frontend `--color-price-*`). Price is a measured quantity — never encoded as good/bad.

**Never encode a variable by colour alone.** Pair colour with marker shape, line style, or a direct
label. Check every figure with a colour-blind simulator (Coblis / Sim Daltonism) and a grayscale
conversion before submission.

## 3. Typography & sizing

- Sans-serif (`Helvetica, Arial, DejaVu Sans`), base 8 pt; titles 8 pt; ticks/legend 7 pt.
- `single_col(height_in=2.4)` → 3.33 in wide; `double_col(height_in=2.6)` → 7.00 in wide.
- Grid: light (`alpha 0.35`), behind data (`axes.axisbelow`). Top/right spines removed.
- Error bars: 95% CI whiskers, capsize 2. Legends frameless.

Apply via:

```python
from experiments.paper_figures import style, templates
style.apply()
templates.figure_f8(steps, "experiments/figures/f8_lmp_spread")
```

## 5. Tables (T6 / T7)

- LaTeX `booktabs` (`\toprule/\midrule/\bottomrule`), **no vertical rules**.
- Caption **above** the table. Report mean ± 95% CI; paired deltas carry the Holm flag and the
  reference regime; a "no detectable pricing effect" note replaces a delta inside the equivalence margin.
- Numbers come from `summary_statistics.json` / `summary.csv` — figures and tables share one source.

---

## 6. Accessibility & reproducibility checklist

- [ ] Colour-blind safe palette; verified with a simulator (not eyeballed).
- [ ] Grayscale-legible: run the strip-copy test; every series still separable.
- [ ] No colour-only encoding — shape/linestyle/direct label present.
- [ ] Base font ≥ 7 pt at final printed size; all fonts embedded in the PDF.
- [ ] Axis labels carry units; no bare numbers.
- [ ] Figure generated by a committed script; no manual annotation edits.
- [ ] Figure numbers agree with the caption and the text reference.
